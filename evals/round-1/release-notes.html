Release notes

Everything new and fixed in Pebble's last five releases. Times are shown in your own timezone.

Latest release

Pebble 4.2 Latest

Released November 4, 2026, 4:30 PM UTC (November 4, 2026).

New

  • Canvas view. Lay notes out on an open board and draw links between them. Open it from any notebook with Ctrl + Shift + K.
  • Daily note templates. Pick a template once and every new daily note starts from it.
  • Export a notebook as a single PDF with a table of contents.

Fixed

  • Checklists no longer lose their order after syncing on two devices at once.
  • Search now finds words inside attached Markdown files.

Earlier releases

Pebble 4.1.2 · October 21, 2026, 3:00 PM UTC

A bug-fix release.

  • Fixed a crash when pasting images larger than 20 MB.
  • Tags with accented letters sort correctly again.
  • Reduced memory use when a notebook has more than 5,000 notes.
Pebble 4.1 · October 7, 2026, 5:00 PM UTC
  • Quick capture. Press Alt + Space from any app to jot a note without opening Pebble.
  • Notes can now be pinned to the top of a notebook.
  • Fixed: dark mode no longer flashes white when switching notebooks.
Pebble 4.0 · September 15, 2026, 2:00 PM UTC
  • End-to-end encrypted sync. Your notes are encrypted on your device before they leave it.
  • A redesigned sidebar with notebooks, tags, and sync status in one place.
  • Offline editing on every platform, with changes merged when you reconnect.
Note: Pebble 4.0 needs macOS 13, Windows 10, iOS 17, or Android 12 or later.
Pebble 3.9.1 · August 26, 2026, 4:00 PM UTC
  • Fixed sync stalling when a note title contained an emoji.
  • Improved startup time by about 30% on older laptops.
  • Updated translations for German, Japanese, and Portuguese.
