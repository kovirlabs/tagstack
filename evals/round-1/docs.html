Getting started with shipit

Deploy a folder to any host from your terminal or your CI pipeline in one command.

shipit is a CLI that builds, uploads, and activates a release of your site or service, then keeps the last five releases so you can roll back in seconds. It talks to hosts over SSH or to object storage such as S3.

Requirements

  • Node.js 20 or later.
  • An SSH key or an API token for your host.
  • Git, if you want shipit to tag each release with the commit it came from.

Install

Install shipit globally with npm:

npm install --global shipit

Or, on macOS and Linux, with Homebrew:

brew install shipit

Check the install

shipit --version
# shipit 3.4.1

Usage

Run shipit from the folder you want to publish. The first run asks for a target and writes it to shipit.toml.

shipit deploy --target production

Preview a deploy

See which files would change without uploading anything:

shipit deploy --target staging --dry-run

Roll back

Switch back to the previous release. Press Ctrl + C at the prompt to cancel.

shipit rollback --target production

Deploy from CI

In CI, pass the token through an environment variable and skip the prompts:

export SHIPIT_TOKEN="$DEPLOY_TOKEN"
shipit deploy --target production --yes --quiet
Tip: Run shipit deploy --dry-run on pull requests and the real deploy only on your main branch.

Command-line options

Every option can also be set in shipit.toml. Options on the command line win. Click a column header to sort.

FAQ

Does a deploy cause downtime?

No. shipit uploads the new release next to the current one and switches a symlink (or an object-storage prefix) only after every file is in place.

Where should I keep my token?

In the SHIPIT_TOKEN environment variable, or in your CI provider's secret store. Never commit it to shipit.toml.

Can I deploy several apps from one repository?

Yes. Add a target per app in shipit.toml, each with its own dir, and run shipit deploy --target once for each.

Does the CLI work on Windows?

Yes, on Windows 10 and later with Node.js 20. Use PowerShell or Windows Terminal.
