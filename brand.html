The brand

One mark, one violet, and one shared theme. Every family site links the same file, so a change here shows up everywhere.

The mark

Angle brackets around a slash: a closing tag, on a violet square. It reads the same in light and dark mode.

Color and type

TokenValueUse
--color-primary #7c3aedThe mark, buttons, links, and focus rings. TagBrush.css darkens or lightens links as needed to stay readable.
--color-on-primary #ffffffText on violet: 5.7:1.
NeutralsTinted with the violetBackground, surface, text, and borders, from TagBrush.css's formulas.
--font-weight-heading700Headings, in the system font.
--border-radius0.5remButtons, fields, cards, and code blocks.

Use the theme

Link it after TagBrush.css. It holds only TagBrush.css variables and the family bar's few rules.

<link rel="icon" href="https://kovirlabs.github.io/tagstack/mark.svg" type="image/svg+xml">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/tagbrush@1/tagbrush.min.css">
<link rel="stylesheet" href="https://kovirlabs.github.io/tagstack/brand.css">

A page that has to show TagBrush.css's default look, like TagBrush.css's own demo, adds data-brand="chrome" to <html>: only the family bar and the footer carry the brand.

The family bar

The first thing in each site's <header>, before the site's own navigation. Mark the current site with aria-current="page".

The footer

The site's own line first, then the family line.

<footer data-brand="footer">
  <p>…about this site…</p>
  <p>Part of the <a href="https://kovirlabs.github.io/tagstack/">Tag family</a> from Kovir Labs.</p>
</footer>

Keep to

  • Write the name as Tag family, and each tool as TagBrush.css, TagAction, TagCheck, TagKit.
  • No classes for the brand: it styles data-brand elements and TagBrush.css variables only, so every family page still passes TagCheck.
  • Don't recolor the mark. On a photo or a busy background, put it on a plain surface.
